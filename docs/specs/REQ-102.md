## 需求描述 (Requirement Description)

支持 Tile 级的高清纹理替换，让游戏画面更清晰。

功能要求：
1. Tile 提取与识别（从 CHR ROM/RAM 提取 Tile 数据）
2. 高清 Tile 替换（用户提供的 PNG/其他格式）
3. 精灵（Sprite）高清替换
4. 背景 Tile 高清替换
5. 调色板感知替换（同一 Tile 不同调色板可对应不同高清纹理）
6. 替换规则配置（JSON/其他格式）
7. 运行时热加载（替换纹理无需重启）
8. 原始/高清切换（实时对比）

## 验收标准 (Acceptance Criteria)

1. 正确提取 CHR ROM 中的所有 Tile（8x8 像素，2bpp）
2. 用户提供的 PNG 文件能正确替换对应 Tile
3. 精灵和背景 Tile 均可替换
4. 调色板感知替换正确（同一 Tile 不同调色板使用不同纹理）
5. 替换规则配置文件格式清晰、易编辑
6. 修改替换文件后热加载生效（≤ 1 秒）
7. 实时切换原始/高清模式，画面正确更新
8. 不支持替换的 Tile 降级使用原始渲染
