## 需求描述 (Requirement Description)

实现简单的配置文件读写，保存窗口尺寸、音量、键位映射、最近一次加载的 ROM 路径等。

要求：
1. 文件格式：纯文本 key=value，每行一项，注释以 `#` 起始
2. 默认路径 `~/.config/fcemu/config.ini`（或 Windows 等价路径），允许命令行覆盖
3. 启动时若不存在则使用内置默认；退出时回写

## 验收标准 (Acceptance Criteria)

1. 修改键位后重启仍生效
2. 损坏文件被检测并回退默认（不崩溃）
3. 单元测试覆盖解析、序列化、缺失字段
