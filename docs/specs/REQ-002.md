## 需求描述 (Requirement Description)

实现 PPU（Picture Processing Unit）的完整渲染功能，包括背景和精灵的渲染。

功能要求：
1. 实现 PPU 寄存器（$2000-$2007）的读写模拟
2. 正确渲染背景层（从名称表和图案表）
3. 正确渲染精灵层（从 OAM 和图案表）
4. 实现调色板系统（背景调色板 $3F00-$3F0F，精灵调色板 $3F10-$3F1F）
5. 支持水平/垂直/四屏幕镜像
6. 实现扫描线级渲染时序（262 条扫描线，NTSC）
7. 实现精灵 0 碰撞检测（Sprite 0 Hit）
8. 实现精灵溢出标志（Sprite Overflow）
9. 支持滚动（PPUSCROLL $2005）
10. 正确模拟 VBlank 标志和 NMI 触发

## 验收标准 (Acceptance Criteria)

1. 背景正确渲染 32x30 个 Tile（256x240 像素）
2. 精灵正确渲染（最多 8 个/扫描线，64 个/帧）
3. 调色板正确映射颜色（56 种可用颜色）
4. 水平/垂直翻转正确
5. 精灵优先级正确（高 OAM 索引优先 / 背景优先设置）
6. 精灵 0 碰撞正确检测并触发 $2002 bit 6
7. 超过 8 个精灵/扫描线时设置溢出标志 $2002 bit 5
8. VBlank 标志在扫描线 241 正确设置，触发 NMI（如果使能）
9. 滚动正确工作（包括细滚动 fine X）
10. 名称表镜像正确（水平/垂直/四屏幕）
11. 渲染开关（$2001 bit 3/4）正确控制背景/精灵显示

## 备注 (Notes)

- PPU 渲染在后台执行，与 CPU 并行（模拟时序）
- 扫描线 0-239 可见，240 空闲，241-261 VBlank，261 预渲染
- 读取 $2007 时有缓冲行为，第一次读取返回延迟的值
