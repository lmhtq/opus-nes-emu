## 需求描述 (Requirement Description)

实现游戏资源分析器，打开游戏时自动分析并提取可替换的资源。

功能要求：
1. ROM 自动分析（识别游戏、读取 CHR/PRG）
2. 音乐提取（识别 APU 各通道的音乐模式）
3. 音效提取（识别常见音效模式）
4. Tile 提取（从 CHR ROM/RAM 提取所有 Tile）
5. 精灵提取（从 OAM 和图案表提取精灵）
6. 调色板提取（当前使用的调色板）
7. 资源清单生成（JSON 格式，列出所有可替换资源）
8. 资源预览（在 UI 中预览提取的资源）

## 验收标准 (Acceptance Criteria)

1. ROM 正确分析，游戏识别准确（至少支持 20 个常见游戏）
2. 音乐正确提取（至少识别 Pulse 1/2、Triangle 通道的旋律）
3. 音效正确提取（至少识别 10 种常见音效：跳跃/爆炸/射击等）
4. Tile 正确提取（8x8，2bpp 格式）
5. 精灵正确提取（8x8 或 8x16）
6. 调色板正确提取（背景 + 精灵调色板）
7. 资源清单格式清晰，包含唯一标识符和元数据
8. 资源预览功能正确（在 UI 中显示 Tile/精灵/调色板）
