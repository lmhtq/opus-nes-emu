## 需求描述 (Requirement Description)

实现 FC/NES 标准手柄的输入模拟。

功能要求：
1. 实现标准手柄的按钮状态读取（A/B/Select/Start/Up/Down/Left/Right）
2. 实现手柄选通（Strobe）机制（$4016 写入 1 然后 0）
3. 实现移位寄存器读取（每次读 $4016/$4017 返回 1 bit）
4. 支持 2 个手柄
5. 支持键位映射（键盘到手柄按钮）
6. 支持真实手柄输入（通过 SDL/其他库）

## 验收标准 (Acceptance Criteria)

1. 手柄选通正确：写入 1 加载按钮状态，写入 0 开始移位
2. 连续读取 8 次 $4016 正确返回所有按钮状态（A→B→Select→Start→Up→Down→Left→Right）
3. 按钮按下返回 1，松开返回 0
4. 第 9 次及以后读取返回 1（移位寄存器空）
5. 2 个手柄独立工作（$4016=$4017）
6. 键盘映射正确响应
7. 真实手柄输入正确识别（如果支持）

## 备注 (Notes)

- 标准手柄使用 8-bit 移位寄存器
- 其他设备（Zapper 光枪、Power Pad）可后续支持
- 选通后按钮状态在移位寄存器中保持稳定
