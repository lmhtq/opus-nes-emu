## 需求描述 (Requirement Description)

在 REQ-004 的基础上，明确支持的 Mapper 列表与切换语义。

要求实现：
1. **Mapper 0 (NROM)**：固定 PRG 16K/32K，CHR 8K
2. **Mapper 1 (MMC1)**：5-bit 移位寄存器，PRG/CHR bank 切换，可选 8KB PRG-RAM
3. **Mapper 2 (UxROM)**：可切换 16KB PRG bank（低位），固定 16KB（高位）
4. **Mapper 3 (CNROM)**：仅 CHR ROM 8KB bank 切换
5. **Mapper 4 (MMC3)**：8 个寄存器 ($8000~$E001)，scanline IRQ 计数

## 验收标准 (Acceptance Criteria)

1. 各 Mapper 的 ROM 加载后正确报告映射器号
2. 写入对应控制寄存器后，PRG/CHR 窗口切换到正确 bank
3. MMC1 移位寄存器 reset bit 正确处理
4. MMC3 scanline IRQ 在配置周期触发，CPU 正确响应
5. 单元测试覆盖每个 Mapper 至少 3 个 case
