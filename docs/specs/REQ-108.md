## 需求描述 (Requirement Description)

在播放时显示音频波形、频谱等可视化效果，可选叠加在游戏画面上。

功能要求：
1. 音频波形显示（时域波形）
2. 频谱分析显示（频域，FFT）
3. 可叠加在游戏画面上（半透明）
4. 可独立窗口显示
5. 多种可视化样式（条形图/波形/环形等）
6. 颜色/透明度可调
7. 与游戏场景联动（不同场景不同样式）

## 验收标准 (Acceptance Criteria)

1. 音频波形正确显示（与音频同步，延迟 < 50ms）
2. 频谱分析正确（频率范围 20Hz-20kHz）
3. 叠加模式正确（半透明，不遮挡游戏关键内容）
4. 独立窗口模式工作正常
5. 至少 3 种可视化样式可选
6. 颜色/透明度实时可调
7. 可开关，不影响游戏性能（CPU 占用增加 ≤ 5%）
