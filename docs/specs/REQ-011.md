# REQ-011 — 输入设备配置（手柄 + 连发）

## 目标
为玩家提供完整的输入定制能力：

1. **键盘自定义映射**：每个 NES 按钮可被绑定到任意 SDL 键码（`fcemu.ini` 中 `key.<action>=<sdl_key_name>`）。
2. **手柄热插拔**：自动识别系统中的 `SDL_GameController`，最多支持 2 名玩家；支持运行时插拔。
3. **连发（Turbo / 自动连射）**：每个按钮可独立开启连发；连发由帧节拍驱动，频率可配置（默认每 2 帧切换 → 30Hz）。

## 详细需求

| ID | 描述 | 验收标准 |
|----|------|----------|
| 011-1 | P1 / P2 键盘默认布局 | 默认即可双打：P1 = 方向键 + Z/X + RShift/Return；P2 = IJKL + G/H + V/B |
| 011-2 | 键位 ini 持久化 | 修改保存后下次启动生效；非法键名忽略并使用默认 |
| 011-3 | 手柄按键映射 | NES A = 右脸键（SDL B），NES B = 下脸键（SDL A），DPad → DPad |
| 011-4 | 模拟摇杆 | 左摇杆死区 8000，超出即视为按 D-Pad |
| 011-5 | 连发触发键 | 默认 P1：A 键=连发A，S 键=连发B；P2：T/Y |
| 011-6 | 手柄连发键 | SDL_Y → 连发A；SDL_X → 连发B |
| 011-7 | 连发频率配置 | `turbo.rate_frames=N`（默认 2，最小 1） |
| 011-8 | 多手柄识别 | 启动时枚举；运行中插入/移除自动 attach/detach |

## 配置示例 (`fcemu.ini`)

```ini
key.p1.a=Z
key.p1.b=X
key.p1.up=Up
key.p1.a_turbo=A
key.p1.b_turbo=S
key.p2.up=I
key.p2.down=K
turbo.rate_frames=2
```

## 系统快捷键（不可重映射）
| 键 | 功能 |
|----|------|
| ESC | 退出 |
| F1 / F2 | 存档 / 读档 |
| F5 | Reset |
