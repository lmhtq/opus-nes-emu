## 需求描述 (Requirement Description)

提供基础调试与性能监控能力，便于开发与问题定位。

功能要求：
1. CPU trace：可选地按指令打印 PC、操作码、寄存器、周期数
2. 帧统计：每秒帧数（FPS）、平均帧耗时、APU 缓冲水位
3. 内存窥视：API 形式读取任意 CPU/PPU 地址（不影响时序）
4. 断点（CLI 启动参数）：达到指定 PC 时暂停

## 验收标准 (Acceptance Criteria)

1. trace 模式不会引入运行期内存分配（使用 stderr 直接写）
2. FPS 数据可被 UI 层读取
3. 单元测试覆盖断点命中与 trace 开关
