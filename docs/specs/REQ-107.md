## 需求描述 (Requirement Description)

根据游戏场景自动调整音效参数，增强沉浸感。

功能要求：
1. 场景检测（Boss 战/战斗/探索/菜单等）
2. Boss 战低频增强（检测到 Boss 时增强低音）
3. 战斗场景增强（爆炸/撞击时增强音效）
4. 探索场景柔化（背景音乐增强，音效减弱）
5. 菜单场景简化（只保留 UI 音效）
6. 音效参数自动调整（EQ/混响/音量等）
7. 场景配置文件（JSON 格式，定义触发条件和参数）
8. 用户可自定义场景规则

## 验收标准 (Acceptance Criteria)

1. 场景检测正确（至少支持 Boss/战斗/探索/菜单 4 种场景）
2. Boss 战低频增强可感知（< 200Hz 增益 +3~6dB）
3. 战斗场景音效增强正确
4. 探索场景背景音乐突出
5. 场景切换平滑（音效参数渐变，不突兀）
6. 场景配置文件格式清晰，易编辑
7. 用户可添加自定义场景规则
8. 动态音效可开关（不影响原始音频输出）
