# 6502 CPU 寄存器参考

FC/NES 使用的 Ricoh 2A03/2A07 处理器包含以下寄存器。

## 寄存器列表

### A - 累加器（Accumulator）

| 属性 | 值 |
|------|-----|
| 宽度 | 8-bit |
| 用途 | 算术/逻辑运算的主要工作寄存器 |
| 寻址模式 | Accumulator（隐含寻址，如 `ASL A`） |

常见用法：
```assembly
LDA #$10    ; 加载立即数到 A
ADC $20     ; A = A + Memory[$20] + C
AND #$0F    ; A = A AND #$0F
```

### X - X 索引寄存器

| 属性 | 值 |
|------|-----|
| 宽度 | 8-bit |
| 用途 | 索引寻址、循环计数器、临时存储 |

常见用法：
```assembly
LDX #$00    ; X = 0
INX          ; X = X + 1
LDA $0200,X  ; 使用 X 作为索引
```

### Y - Y 索引寄存器

| 属性 | 值 |
|------|-----|
| 宽度 | 8-bit |
| 用途 | 索引寻址（特别是 Absolute,Y 和 Indirect,Y） |

常见用法：
```assembly
LDY #$00    ; Y = 0
LDA ($10),Y  ; 间接 Y 变址
```

### SP - 栈指针（Stack Pointer）

| 属性 | 值 |
|------|-----|
| 宽度 | 8-bit |
| 用途 | 指向栈顶（实际地址 = $0100 + SP） |
| 初始值 | $FD（复位后） |

注意：
- 栈位于 $0100-$01FF（页 1）
- 栈向**下**增长（PUSH 时 SP 递减，POP 时 SP 递增）
- SP 是 8 位，只占页 1 的偏移量

栈操作：
```assembly
PHA         ; 将 A 压栈：SP--, Memory[$0100+SP] = A
PLA         ; 将 A 出栈：A = Memory[$0100+SP], SP++
PHP         ; 将 STATUS 压栈
PLP         ; 将 STATUS 出栈
JSR $1234   ; 将 PC+2 压栈，然后跳转到 $1234
RTS         ; 从栈中弹出地址，跳回调用者
```

### PC - 程序计数器（Program Counter）

| 属性 | 值 |
|------|-----|
| 宽度 | 16-bit |
| 用途 | 指向下一条要执行的指令地址 |
| 初始值 | 从 $FFFC/$FFFD（复位向量）读取 |

注意：
- 16 位，可寻址 $0000-$FFFF
- 小端序：低字节在前
- 中断/复位时从向量表读取新 PC

### STATUS - 状态寄存器（Processor Status）

| 属性 | 值 |
|------|-----|
| 宽度 | 8-bit |
| 用途 | 存储 CPU 标志位 |

#### 标志位布局

```
Bit:  7   6   5   4   3   2   1   0
    +---+---+---+---+---+---+---+---+
    | N | V |   | B | D | I | Z | C |
    +---+---+---+---+---+---+---+---+
```

| 位 | 名称 | 说明 |
|----|------|------|
| 0 (C) | Carry | 进位/借位标志。加法进位或减法借位时置位 |
| 1 (Z) | Zero | 零标志。运算结果为 0 时置位 |
| 2 (I) | Interrupt Disable | 中断禁用。置位时忽略 IRQ（BRK 和 NMI 仍有效） |
| 3 (D) | Decimal Mode | **NES 中无效**。6502 的 BCD 模式在 2A03 中被移除 |
| 4 (B) | Break | BRK 指令触发时置位。硬件中断时清除 |
| 5 | - | 未使用，**始终为 1** |
| 6 (V) | Overflow | 溢出标志。有符号溢出时置位（BIT 指令也会设置） |
| 7 (N) | Negative | 负数标志。结果最高位（bit 7）为 1 时置位 |

#### 标志位操作指令

| 指令 | 操作 | 说明 |
|------|------|------|
| CLC | C = 0 | 清除进位 |
| SEC | C = 1 | 设置进位 |
| CLI | I = 0 | 清除中断禁用（允许 IRQ） |
| SEI | I = 1 | 设置中断禁用（禁止 IRQ） |
| CLV | V = 0 | 清除溢出标志 |
| CLD | D = 0 | 清除十进制模式（NES 上无效果） |
| SED | D = 1 | 设置十进制模式（NES 上无效果） |

## 复位状态

| 寄存器 | 复位后的值 |
|--------|-------------|
| PC | 从 $FFFC/$FFFD 读取 |
| SP | $FD |
| A | 未定义 |
| X | 未定义 |
| Y | 未定义 |
| STATUS | 中断禁用位置位（I=1），其他位不确定 |
