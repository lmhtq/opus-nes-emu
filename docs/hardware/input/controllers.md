# FC/NES 输入设备参考

FC/NES 标准手柄通过 $4016（手柄 1）和 $4017（手柄 2）寄存器访问。

## 标准手柄（Standard Controller）

### 寄存器

| 地址 | 方向 | 说明 |
|------|------|------|
| $4016 | Write | 手柄选通（Strobe）：写入 1 然后 0 |
| $4016 | Read | 手柄 1 数据（每次读取返回 1 bit） |
| $4017 | Read | 手柄 2 数据 |

### 数据格式

每次读取 $4016/$4017 返回 1 bit（在 bit 0），共需读取 8 次：

| 读取顺序 | 按钮 | 说明 |
|----------|------|------|
| 1 | A | 按钮 A |
| 2 | B | 按钮 B |
| 3 | Select | Select 按钮 |
| 4 | Start | Start 按钮 |
| 5 | Up | 方向键上 |
| 6 | Down | 方向键下 |
| 7 | Left | 方向键左 |
| 8 | Right | 方向键右 |

> 按钮按下时返回 1（bit 0 = 1），松开时返回 0。
> 第 9 次及以后的读取始终返回 1（因为移位寄存器空了）。

### 读取流程

```assembly
; 选通手柄（Strobe）
LDA #$01
STA $4016
LDA #$00
STA $4016

; 读取 8 次，每次 1 bit
LDX #$08
Loop:
    LDA $4016       ; 读取 1 bit（在 bit 0）
    LSR A           ; 右移，bit 0 进入进位标志
    ; 此时 C=1 表示按钮按下
    DEX
    BNE Loop
```

### 状态寄存器读取

每次读取 $4016/$4017 时：
- 第一次读取：返回当前移位寄存器的最高位（MSB）
- 之后每次读取：移位寄存器右移 1 位，返回新的 MSB
- 8 次读取后，移位寄存器为空，后续读取返回 1

## 选通（Strobe）机制

写入 $4016：
- 写入 1：手柄内部移位寄存器加载当前按钮状态
- 写入 0：开始移位模式（每次读取移位 1 bit）

注意：如果不执行选通（直接读取），只会得到静态的移位寄存器值。

## 其他输入设备

### Zapper（光枪）

- 通过 $4016/$4017 的 bit 3（光检测）和 bit 4（触发按钮）访问
- 光检测：bit 3 = 1 表示检测到亮光（如 CRT 扫描线经过白色区域）
- 触发：bit 4 = 1 表示扳机按下

### Power Pad（力量垫）

- 12 个压力感应垫
- 通过 $4016/$4017 的 bit 0-3 访问（4-bit 数据，需多次读取）

### Four Score（四人适配器）

- 允许连接 4 个手柄
- 通过特殊握手协议识别（先读取 $4016/$4017 的 bit 0-1 多次）

## 输入时序

- 手柄选通后，按钮状态在移位寄存器中保持稳定
- 每次读取 $4016/$4017 后，内部移位寄存器自动右移
- CPU 可以在 VBlank 期间读取手柄状态（通常 NMI 中处理）
