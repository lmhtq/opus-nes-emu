# PPU 精灵（Sprite）处理参考

FC/NES 的 PPU 支持最多 64 个精灵（Sprite/Object），每帧最多显示 8 个精灵在同一扫描线上。

## OAM（Object Attribute Memory）

### OAM 结构

OAM 共 256 字节（64 个精灵 × 4 字节/精灵）。

| 字节 | 名称 | 说明 |
|------|------|------|
| 0 | Y Position | 精灵的 Y 坐标（屏幕 Y = Y + 1） |
| 1 | Tile Index | 图案表中的 Tile 编号 |
| 2 | Attributes | 属性（调色板、翻转、优先级） |
| 3 | X Position | 精灵的 X 坐标 |

### 属性字节（Byte 2）详解

| 位 | 名称 | 说明 |
|----|------|------|
| 0-1 | Palette | 调色板选择（0-3，对应 $3F10, $3F14, $3F18, $3F1C） |
| 2-4 | Unused | 未使用 |
| 5 | Priority | 0=前景（覆盖背景），1=背景（被背景覆盖） |
| 6 | Flip Horizontal | 1=水平翻转 |
| 7 | Flip Vertical | 1=垂直翻转 |

## 精灵评估（Sprite Evaluation）

在每条扫描线的 257-320 阶段（约 64 个 PPU 时钟），PPU 执行精灵评估：

### 第一阶段：扫描 OAM（257-320）

1. 从 OAM 地址 0 开始，检查每个精灵的 Y 位置
2. 如果精灵的 Y 在当前扫描线上（Y <= scanline < Y + 8 或 16），则加入候选列表
3. 最多收集 8 个精灵（如果超过 8 个，设置溢出标志 $2002 bit 5）
4. 将选中的精灵数据复制到二级 OAM（sprite buffer）

### 精灵 0 碰撞检测

- 在每条扫描线的 256 阶段检查
- 如果精灵 0 的非透明像素与背景的非透明像素重叠，设置 $2002 的 bit 6（Sprite 0 Hit）
- 常用于实现扫描线特效（如状态栏分离）

## 精灵渲染

### 8x8 精灵

- 使用 $2000 的 bit 2=0
- 图案表由 Tile Index 的 bit 0-7 指定
- 每个精灵 8x8 像素，使用 4 种颜色（1 种透明 + 3 种来自调色板）

### 8x16 精灵

- 使用 $2000 的 bit 2=1
- 图案表由 Tile Index 的 bit 0 选择（0=使用 $0000 的上半部分，1=使用 $1000 的下半部分）
- Tile Index 的 bit 1-7 指定 Tile 编号（实际使用两个连续的 Tile）
- 上半部分 Tile 和下半部分 Tile 各 8 像素高

### 精灵翻转

- **水平翻转**：像素读取顺序反转（Tile 像素 7→0 变为 0→7）
- **垂直翻转**：行读取顺序反转（行 0-7 变为 7-0）

## 精灵调色板

精灵调色板位于 PPU 地址空间 $3F10-$3F1F：

| 地址 | 说明 |
|------|------|
| $3F10 | 精灵调色板 0，通用背景色（镜像 $3F00） |
| $3F11 | 精灵调色板 1 |
| $3F12 | 精灵调色板 2 |
| $3F13 | 精灵调色板 3 |
| $3F14 | 精灵调色板 0（镜像 $3F04） |
| $3F15 | 精灵调色板 1 |
| $3F16 | 精灵调色板 2 |
| $3F17 | 精灵调色板 3 |
| $3F18 | 精灵调色板 0（镜像 $3F08） |
| $3F19 | 精灵调色板 1 |
| $3F1A | 精灵调色板 2 |
| $3F1B | 精灵调色板 3 |
| $3F1C | 精灵调色板 0（镜像 $3F0C） |
| $3F1D | 精灵调色板 1 |
| $3F1E | 精灵调色板 2 |
| $3F1F | 精灵调色板 3 |

> 注意：精灵调色板的 0 号颜色（每 4 个一组的第一个）是透明的，实际上使用背景色。

## 精灵限制

| 限制 | 值 | 说明 |
|------|-----|------|
| 每帧最大精灵数 | 64 | OAM 容量 |
| 每扫描线最大精灵数 | 8 | 超过的精灵不显示，设置溢出标志 |
| 精灵大小 | 8x8 或 8x16 | 由 $2000 bit 2 控制 |
| 调色板数 | 4 | 每个精灵可选 4 个调色板之一 |
| 颜色数 | 3+透明 | 每个精灵使用 4 种颜色（含透明） |

## 精灵 0 的特殊性

- 精灵 0 用于碰撞检测（Sprite 0 Hit）
- 常用于分割屏幕（如《超级马里奥兄弟》的分数栏）
- 只有精灵 0 会设置 $2002 的 bit 6
- 其他精灵的碰撞不触发任何标志
