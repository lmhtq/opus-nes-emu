# APU 音频通道参考

FC/NES APU 包含 5 个音频通道：2 个脉冲波（Pulse）、1 个三角波（Triangle）、1 个噪声（Noise）、1 个 DMC（Delta Modulation Channel）。

## 脉冲波通道（Pulse 1 & Pulse 2）

两个完全相同的脉冲波通道，位于 $4000-$4003 和 $4004-$4007。

### 输出波形（占空比）

| 位 6-7 | 占空比 | 波形 |
|--------|--------|------|
| 00 | 12.5% | ▁▁▁▁▁▁▁█ |
| 01 | 25% | ▁▁▁▁▁███ |
| 10 | 50% | ▁▁█████ |
| 11 | 75% | ███████▁ |

### 包络（Envelope）

- 当 $4000 的 bit 5=0 时，使用包络衰减
- 包络从 15 开始，每 N 个帧递减 1（N 由位 0-3 决定）
- 当 $4000 的 bit 4=1 时，包络循环（不停止）
- 当 $4000 的 bit 5=1 时，使用固定音量（位 0-3）

### 扫频（Sweep）

- 周期：每 N 帧检查一次（N 由 $4001/$4005 的位 4-6 决定）
- 移位：每次将定时器值右移（位 0-2 决定移位数）
- 方向：位 3 决定加法（频率降低）或减法（频率升高）
- 使能：位 7 使能扫频

### 长度计数器（Length Counter）

- 当 $4000/$4004 的 bit 4=1 时，长度计数器停止
- 写入 $4003/$4007 时载入长度值（查表）
- 帧计数器每执行一步，长度计数器减 1（到 0 停止输出）

## 三角波通道（Triangle）

位于 $4008-$400B。

### 特性

- 固定音量（无包络，固定 4-bit DAC = 16 级）
- 线性计数器：由 $4008 控制
- 长度计数器：同脉冲波

### 线性计数器

- 当 $4008 的 bit 7=1 时，线性计数器 reload
- Reload 值：位 0-6
- 每帧：如果 control=1 或 reload=1，则计数器 = reload 值；否则计数器减 1

### 频率

三角波频率 = CPU时钟 / (32 × (定时器值 + 1))

## 噪声通道（Noise）

位于 $4010-$4013（注意：映射与 DMC 重叠，但实际是噪声通道）。

| $3 | 32 | 55930 |
| $4 | 64 | 27965 |
| $5 | 96 | 18643 |
| $6 | 128 | 13983 |
| $7 | 160 | 11186 |
| $8 | 202 | 8862 |
| $9 | 254 | 7046 |
| $A | 380 | 4708 |
| $B | 508 | 3521 |
| $C | 762 | 2347 |

### 模式

- 位 7=0：短模式（15 位噪声，周期短，声音更"尖锐"）
- 位 7=1：长模式（1 位噪声，周期长，声音更"柔和"）

## DMC 通道（Delta Modulation Channel）

位于 $4010-$4013（实际是 DMC，不是噪声）。

### DMC 寄存器

| 地址 | 名称 | 说明 |
|------|------|------|
| $4010 | DMC Control | IRQ 使能、循环、频率索引 |
| $4011 | DMC Direct Load | 直接加载 DAC 值（6-bit） |
| $4012 | DMC Sample Address | 采样地址 = $C000 + (值 × $0040) |
| $4013 | DMC Sample Length | 采样长度 = (值 × $0010) + $0001 |

## 混音

APU 输出是各通道的近似值混合：

```
输出 = 脉冲1 + 脉冲2 + 三角波 + 噪声 + DMC
```

实际 NES 输出是非线性的，但模拟器通常用线性近似：
- 每个通道输出 0-15 值
- 混音公式：`output = 0.00752 * (pulse_out + triangle_out + noise_out + dmc_out)`
