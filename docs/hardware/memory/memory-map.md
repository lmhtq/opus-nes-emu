# NES 内存映射参考

FC/NES CPU 地址空间为 16-bit，可寻址 $0000-$FFFF。

## 完整内存映射

| 地址范围 | 大小 | 说明 |
|----------|------|------|
| $0000-$07FF | 2KB | 内部 RAM（主内存） |
| $0800-$0FFF | 2KB | $0000-$07FF 的镜像 |
| $1000-$17FF | 2KB | $0000-$07FF 的镜像 |
| $1800-$1FFF | 2KB | $0000-$07FF 的镜像 |
| $2000-$2007 | 8B | PPU 寄存器 |
| $2008-$3FFF | 8KB+ | $2000-$2007 的重复镜像 |
| $4000-$4017 | 24B | APU 寄存器 + I/O |
| $4018-$401F | 8B | 未使用（部分扩展使用） |
| $4020-$FFFF | 48KB+ | 卡带空间（PRG ROM/RAM） |

## 详细说明

### 内部 RAM（$0000-$1FFF）

- FC/NES 只有 **2KB** 内部 RAM
- 地址 $0000-$07FF 是实际 RAM
- $0800-$1FFF 是 $0000-$07FF 的**镜像**（A13 不连接）
- 栈位于页 1（$0100-$01FF）

### PPU 寄存器（$2000-$3FFF）

| 地址 | 寄存器 | 说明 |
|------|----------|------|
| $2000 | PPUCTRL | 控制器 |
| $2001 | PPUMASK | 掩码 |
| $2002 | PPUSTATUS | 状态 |
| $2003 | OAMADDR | OAM 地址 |
| $2004 | OAMDATA | OAM 数据 |
| $2005 | PPUSCROLL | 滚动 |
| $2006 | PPUADDR | PPU 地址 |
| $2007 | PPUDATA | PPU 数据 |

> $2008-$3FFF 都是 $2000-$2007 的镜像（只使用 A2-A0 地址线）。

### APU 与 I/O（$4000-$401F）

| 地址 | 说明 |
|------|------|
| $4000-$4003 | 脉冲波 1 |
| $4004-$4007 | 脉冲波 2 |
| $4008-$400B | 三角波 |
| $400C-$400F | 未使用 |
| $4010-$4013 | 噪声 / DMC |
| $4014 | OAM DMA（$4014 写入触发） |
| $4015 | APU 状态 / 通道使能 |
| $4016 | 手柄 1 数据 |
| $4017 | 手柄 2 数据 / 帧计数器 |

### 卡带空间（$4020-$FFFF）

| 地址范围 | 说明 |
|----------|------|
| $4020-$5FFF | 扩展区域（很少使用） |
| $6000-$7FFF | PRG RAM（电池备份 SRAM，可选，8KB） |
| $8000-$BFFF | PRG ROM 低 bank（16KB） |
| $C000-$FFFF | PRG ROM 高 bank（16KB，或镜像 $8000-$BFFF） |

## 特殊页面

### 零页（$0000-$00FF）

- 最快的内存区域（零页寻址模式只需 2 字节指令）
- 常用作临时变量、指针

### 栈页（$0100-$01FF）

- 栈指针 SP 是 8-bit，实际地址 = $0100 + SP
- 栈向**下**增长（PUSH 时 SP--）
- 中断/子程序调用时 PC 和 STATUS 压栈

## 卡带映射器（Mapper）

由于 $4020-$FFFF 的映射由卡带决定，不同游戏使用不同 Mapper：

| Mapper | 名称 | 说明 |
|--------|------|------|
| 0 | NROM | 无银行切换，最简单 |
| 1 | MMC1 | 可变银行切换（如《塞尔达传说》） |
| 2 | UxROM | 切换 $8000-$BFFF（如《超级马里奥兄弟》） |
| 3 | CNROM | 切换 CHR ROM（如《恶魔城》） |
| 4 | MMC3 | 复杂 IRQ + 银行切换（如《洛克人》系列） |

> 完整的 Mapper 列表见 `docs/hardware/cartridge/mappers.md`。
